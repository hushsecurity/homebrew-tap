# homebrew-tap

[Homebrew](https://brew.sh) packages for Hush Security tools, on macOS and Linux.

| Tool | Install |
|---|---|
| [Hush CLI](https://github.com/hushsecurity/hush-cli) | `brew install hushsecurity/tap/hush-cli` |

To upgrade: `brew upgrade hush-cli`.

The casks in `Casks/` are generated by each tool's release; please don't edit
them by hand.
